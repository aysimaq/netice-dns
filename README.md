# 🌐 NETICE DNS

Python tabanlı terminal DNS sorgu aracı.

## Özellikler
- DNS sorgusu (A, AAAA, MX, TXT, NS, CNAME, SOA, PTR)
- Kullanıcı sistemi ve brute-force koruması
- AI destekli domain tahmin/düzeltme
- Admin yönetim paneli ve istatistikler

## Kurulum
```bash
pip install dnspython
python main.py
```

## Gereksinimler
- Python 3.10+
- dnspython
